Web Remote Control Interface
网页远程控制界面

Files in this directory:
本目录文件:

1. bridge_simple.py - Python HTTP bridge server (启动服务器)
2. index_en.html - English web interface (英文界面)
3. index_simple.html - Chinese web interface (中文界面)

How to use:
使用方法:

1. Start bridge server:
   启动桥接服务器:
   python bridge_simple.py

2. Open in browser:
   在浏览器打开:
   index_en.html (English)
   index_simple.html (中文)

The web interface provides full remote control of the AC system.
网页界面提供空调系统的完整远程控制功能。
